# Стенды нативной сборки (build/native, build/native_strict)

Запуск из корня проекта: `node tools/bench/<имя>.js [...]`. Все без окна.

Скорость:
- `r19b.js` — комната 1,9 (3 черепа, огонь, 2 ленты; телепорт, бессмертие, Джо стоит): кадров на шаг, шагов/с. **Главная метрика.** `B=<папка сборки>` — другая сборка.
- `nsteps.js build/native` — обычная игра (ходьба по плану), шагов/с.
- `rsplit.js build/native` — обычный шаг отдельно от смены комнаты.
- `r19f.js` — такты по процедурам с вложенными (`W=disp_prep,crit,...`), на вызов и на шаг.
- `r19g.js` — плоский профиль внутри процедуры (`P=force_live_t`).
- `r19L.js` — профиль по контекстам: L логика, D подготовка вывода, I прерывание.
- `r19h.js` — такты на шаг, простой (ожидание кадра), прерывание.
- `r19site.js` — такты вызовов по местам вызова (`P=cpir,L_9159 R19=1`).
- `r19reg.js` — такты по участкам кода (`REG="имя:метка_от:метка_до,..."`).
- `pschk.js` — сколько готовых сдвигов врагов поместилось (см. docs/NATIVE_VIDEO.md).
- `sktrace.js`, `attrchg.js` — как часто меняются место и кадр спрайтов.

Правильность (должно быть 0 ошибок):
- `scrchk.js build/native 2000 [r19|tp]` — весь экран против эталона: фон по VNT + нарисованные слои объектов (spr_rec); исходная графика MSX — video-ref.js, независимо от кэша Вектора. Проверяется также экран сразу после crit; устаревшая запись dlist не исключает экран, если в PND уже нет ожидающих клеток. Снимок IRQ внутри изменения карты/цветов исключается по video_edit; на каждом L_A5D1 отдельно требуется video_edit=0.
- `cellchk.js build/native 3000 [tp]` (env `FANY=1`, `R19=1 EVERY=1`) — клетки без спрайтов против карты.
- `native-video.js [build/native] [1200]` — точность и неизменяемость готовых сдвигов; скачок катящихся врагов ≤3 пикселей, отставание и расстояние, частоты фаз огня/лент.
- `slsall.sh` — сверка логики с MSX (lockstep) по сборке `build/native_strict` (собрать с `-DSTRICT`). Норма: в каждой строке только `тик 0: 1 байт: 7048=0/1` (старт с меню) и «VRAM совпадает по всем тикам».
