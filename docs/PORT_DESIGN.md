# Устройство порта на Вектор-06Ц

Решения владельца (26.10.2026): экран — 3 плоскости (8 цветов), звук — только ВИ53.
Основа — MSX-версия = картридж ColecoVision (docs/DISASM.md).

## Подход
- Игровая логика картриджа (8025–B104, 4358 команд Z80) переводится на i8080 почти механически:
  631 команда без прямого аналога (357 JR, 135 битовых CB, 38 IX/IY, 16 DJNZ, 10 LDIR, 10 EX AF, 8 CPIR…).
  Поведение остаётся тем же; эталон — модель MSX (tools/msx1.js) с телепортом и читами.
- Платформенный слой пишется заново вместо OS7 и VDP/PSG:
  - «VRAM» таблицы имён — теневая таблица 32×24 в ОЗУ (игра читает её для столкновений, 9159);
    PUT_VRAM/GET_VRAM/FILL_VRAM/WRITE_REGISTER — свои процедуры над теневой таблицей и флагами перерисовки;
  - вывод тайлов в 3 плоскости по шаблону (4 банка — фазы анимации) и цветам группы (таблица цветов 32 байта);
  - программные спрайты (герой — 2 слоя, враги, до ~4–5 одновременно): перерисовка тайлов под старым местом,
    затем вывод поверх;
  - звук: поток команд SN76489 из проигрывателя эффектов (AC1A/AC6D) → делители ВИ53
    (делитель ≈ период SN × 13,41; громкость — вкл/выкл по порогу, шум — опускаем или низкий тон).
- Ресурсы — из build/res (tools/export_res.py), комнаты — данные картриджа как есть (формат — tools/roomdec.py).

## Экран и память
- Плоскости цвета 8000 (бит 3), A000 (бит 2), C000 (бит 1); E000–FFFF — невидимая (палитра парами:
  элементы i и i|1 одинаковы) и свободна под данные.
- Свободно под код и данные: 0000–7FFF + E000–FFFF = 40 КБ.
- Поле MSX 256×192 по центру: строка MSX Y → младший байт адреса 0DFh − Y; столбец тайла c → старший
  байт 80h/A0h/C0h + c.
- Палитра на комнату: до 8 цветов MSX; в 265 комнатах из 297 хватает 8 (с учётом спрайтов и интерфейса),
  в 32 нужно слить 1–2 близких цвета (тёмно-/светло-красный, зелёные).

## Время
- MSX/Coleco — 60 Гц, Вектор — 50 Гц. Логику гонять раз в кадр Вектора (игра на 17 % медленнее) или 6 шагов
  на 5 кадров — решить по замерам.

## Этапы
1. Сборка и стенд: sjasmplus --i8080, tools/vec_emu.js, снимок экрана; вывод любой комнаты на Векторе
   (декодер комнат на i8080 + вывод тайлов в 3 плоскости + палитра) со сверкой с рендером MSX.
2. Перевод логики, OS7-слой, ввод, спрайты; сверка с моделью MSX по ходу игры (позиции, комнаты).
3. Звук ВИ53, интерфейс, заставка; ROM/дискета, проверка на MiSTer.

## Этап 1 — сделан (26.10.2026)
- `src/vec/viewer.asm` + `room.asm` (декодер комнат на i8080) + `render.asm` (цвета комнаты, палитра со
  слиянием, вывод в 3 плоскости); данные — `tools/mkvecdata.py` → `src/vec/gen/data.asm`.
- Стенд: `tools/vroom.js` (vector06js без окна, запросы req_lv/req_row/req_room → done), сверка `tools/vcheck.py`:
  таблица имён 297/297, пиксели 297/297 (индексы Вектора = карта цветов программы от цвета MSX).
  Карты уровней с экрана Вектора — build/vec/rooms/map_L<у>.png.
- Код и данные просмотра — 7,7 КБ (0100–1F00); вывод комнаты целиком ~87 кадров (не оптимизировано).
- Сборка: `python3 -I tools/mkvecdata.py && (cd src/vec && ../../tools/sjasmplus --nologo --i8080 --sym=../../build/vec/viewer.sym viewer.asm)`.

## Этап 2 — перевод логики (начат 26.10.2026)
- `tools/z2i.py` → `src/vec/gen/game.asm` (3373 команды картриджа 800C–BFFF, метки L_/D_, таблицы указателей
  8913, A20A, 9477, AD0B и записи AE00), `src/vec/gen/zhelp.asm` (LDIR, CPIR, EX AF, EXX, NEG, SBC HL, сдвиги CB
  с флагами Z80), отчёт `build/vec/z2i_report.txt` — 0 предупреждений. Ручная вставка: `src/vec/manual/AE46.asm`;
  IY в начислении очков (AF70–AFC7) = 7017. Константы среди адресов: 8282 (AA55).
- Разметка исправлена: встроенные параметры AE00 (9 мест) — данные; 816D/8179/9207 — не перекрытия, а сбой Ghidra.
- Структура: 8025 старт (OS7, графика через AE00) → 8179 меню прослойки (2227, код клавиши 73F0: 82/88/83 =
  уровень 1/2/3) → 817C → A59D игра; кадр — A9B3 (вектор 8021 вместо NMI VDP, работает на теневых регистрах).
- Внешние вызовы для платформенного слоя: OS7 — WRITE_REGISTER 13, FILL_VRAM 9, LOAD_ASCII 3, REFLECT_VERTICAL 3,
  PUT_VRAM 2, GET_VRAM 2, WR_SPR_NM_TBL 2, TURN_OFF_SOUND 4, REFLECT_HORIZONTAL, ENLARGE, INIT_SPR_ORDER,
  READ_REGISTER, CONTROLLER_SCAN, MODE_1; прослойка — звук 21C5/21CA/21CF/21D4, 21DE, меню 2209/2227.

## Этап 2 — игра запускается на Векторе (26.10.2026)
- Сборка: `python3 -I tools/mkvecdata.py && python3 -I tools/z2i.py && (cd src/vec && ../../tools/sjasmplus --nologo
  --i8080 --sym=../../build/vec/monty.sym game.asm)` → build/vec/monty.bin (образ с 0000, до 6180h).
- Платформа: `src/vec/os7.asm` (виртуальная VRAM, функции OS7, REFLECT/ENLARGE, шрифт OS7),
  `adapter.asm` (клавиатура -> CONTROLLER_SCAN, меню 1/2/3, 2209, 21DE, байты SN76489), `display.asm` +
  `cell.asm` (вывод изменённого, банки анимации, цвета, палитра комнаты), `sprites.asm` (программные спрайты),
  `game.asm` (загрузка, прерывание со своим стеком, отложенный «NMI» A9B3).
- Стенды: `tools/vshot.js` (снимки), `tools/vtrace.js` (первые исполнения меток), `tools/vprof.js` (профиль),
  `tools/vcrash.js` (выход исполнения из кода). Первый запуск: титульник, вступление, стартовая комната —
  docs/vec_first_run.png.
- Найдено по пути: таблица процессов A8A1 (указатели на 91E5, 8F5F, 88D1, A8D6); слова-указатели на стыке
  строк DEFW — транслятор склеивает подряд идущие данные.
- Дальше: сверка с моделью MSX по тикам обработчика (ОЗУ 7000–73FF), скорость, звук ВИ53, ввод (джойстик «П»).
