# Нативная версия i8080 (с 26.10.2026)

С 28.10 обычная сборка по умолчанию использует полный экран NES 256×240,
HUD и музыку: [NES_NATIVE.md](NES_NATIVE.md). Описание ниже сохраняет
устройство прежней MSX-геометрии; она остаётся в сборке STRICT для сверки.

Нативная сборка i8080: логика вручную по JS-модели (src/model), сверена с MSX;
прямой вывод без программного VDP. В комнате 1,9 по r19b скорость 50,0 шага/с;
логика ускорена в 1,53 раза до 12122 тактов/шаг, остаётся неравномерность
отдельных шагов. Замеры — docs/LOGIC_OPT.md; устройство вывода — docs/NATIVE_VIDEO.md.
src/vec (перевод z2i + слой OS7) остаётся отдельной сборкой.

## Устройство
- **ОЗУ игры 7000-73FF** — та же раскладка, что у MSX (все переменные, 7300 атрибуты спрайтов, 72C0 объекты,
  7086 враги, 70C0 флаги взятия, 71B2 инвентарь). Сверка — tools/lockstep.js по итерациям главного цикла.
- **Данные картриджа** — tools/mknative.py: блоки данных (b/w разметки) как есть, метка C_xxxx на каждый
  адрес (EQU), слова-указатели в данные — dw C_xxxx. Таблицы переходов (8913, A20A, A8A1) — свои в коде.
- **Графика** — неизменяемые исходные полосы тайлов и 42 различных кадра спрайтов.
  Готовый тайл — три полосы Вектора по 8 байт; все кадры живого тайла строятся вместе.
  Готовые сдвиги врагов размещаются в свободных областях основной и невидимой памяти.
- **Вывод** — VNT (768 байт) остаётся картой игры, room_colors (32) — её цветами.
  fire_frame/belt_frame непосредственно задают анимацию. Карта сообщает об изменённых
  клетках; объекты читаются из 7300 в порядке 72E0 без копии SAT. Постоянные дескрипторы
  хранят показанные атрибуты, область сохранения фона и готовую графику. Подготовка
  идёт вне прерывания; восстановление, клетки под объектами и спрайты — в начале IRQ.
  Враги рисуются в 8000, OR; Джо использует общий фон двух слоёв.
- **Логика** — модули по src/model: main (A5D1, процессы), frame (A9B3), hero (88D1), enemy (A7A1), collide
  (91E5, 8F5F, предметы), drawroom (A067), screen (8EB0, A60B), sound (AC1A/AC6D + SN -> ВИ53), score/HUD.
- **Клавиатура** — только в начале прерывания (порт 03 — и прокрутка экрана).

## Этапы (каждый — сверка lockstep)
1. Данные и каркас: сборка src/native, загрузка, снимок шаблонов, vid + вывод, начальное состояние уровня.
2. Рисование комнаты A067 и экран (8EB0, A60B): таблица имён и цвета совпадают с MSX после смены комнаты.
3. Главный цикл, обработчик кадра, звук эффектов.
4. Враги, предметы, столкновения.
5. Герой.
6. Меню, конец игры, следующий уровень; ВИ53, джойстик «П».
