## Неделимая группа Джо и врагов: irq-group (9.11.2026)

База — fix38 `b713908`, оптимизация — `2f9ff25`. Одинаковое окружение: Node.js 26.4.0, штатный vector06js. Сборки `build/irq-base`, `build/irq-group`, `build/irq-group-rus`; исходный worktree и `build/quick`, `build/fix3*`, `build/rus3*` не менялись.

`cover_set` / `cover_clear` теперь вычисляют первый адрес PND один раз и переходят между строками прибавлением смещения. Ширина и число строк также вычисляются один раз. После последней клетки указатель возвращается на неё перед прибавлением `33-width`: перенос из L в H сохраняется даже при правом крае в столбце 31. Биты чужих спрайтов, pending-bit, пропуск неподвижной области, порядок атомарной группы и все `PACE_*` сохранены.

### Регрессии

Новый `nes-cover-rect.js` выполняет реальный i8080-код: **14 022 прямоугольника**, все строки и столбцы, ширины 1/2/3/4/32, высоты 1…4, обрезка, переходы страниц, защитные байты, посторонние биты, регистры/флаги/стек и 6 неподвижных областей. Проходит на fix38, английской и русской новой сборке.

`REUSE_REFERENCES=1 B=… sh tools/nes/diff_audits.sh`: полностью одинаковый результат до/после: ledge 0, wall 0, wall2 0, ropejump 0, wall3 0, **walljump 26**, **belt 136** расхождений с NES.

Полный набор: 96 стендов (все `nes-*.js` и `restart-enemies.js`, кроме `*physics-audit*`, `*splash*`, `*ladder-gameplay*`, включая новый `nes-cover-rect`). fix38: 74 успешных, irq-group: 75 успешных. Новых падающих стендов нет.

Исправлены падения: `nes-frame-pacing`.

Сохраняются падения, воспроизводимые и на fix38 (это не полностью зелёный набор): `nes-chain-approach`, `nes-chain-descent`, `nes-chain-exit`, `nes-chain-landing`, `nes-chain-live`, `nes-chain-release`, `nes-chain-walk`, `nes-climb-audit`, `nes-climb-caps`, `nes-climb-live`, `nes-death-paths`, `nes-enemy-seeds`, `nes-ink-cost`, `nes-ink-planes`, `nes-joe-byte-special`, `nes-joe-prep-pair`, `nes-preparation-cost`, `nes-room-entry`, `nes-room-transitions`, `nes-rope-top`, `nes-vase`.

Для стендов с позиционными аргументами переданы пути сборок; для `nes-joe-byte-special` и `nes-joe-prep-pair` сначала собраны их изолированные экспериментальные образы штатными скриптами. `nes-video-ref` также используется как эталон внутри `framecheck`, а не только загружается отдельно.

### Воспроизведение

```sh
sh tools/nes/quick_build.sh build/irq-group
sh tools/nes/build_rus.sh build/irq-group-rus
PROFILE=1 PIXELS=1 B=build/irq-group ROOM=7,2 MOVING=1 XOFF=112 node tools/bench/nes-frame-pacing.js
B=build/irq-group node tools/bench/nes-cover-rect.js
node tools/bench/ps-alloc.js build/irq-group
node tools/bench/ps-alloc.js build/irq-group-rus
REUSE_REFERENCES=1 B=build/irq-group sh tools/nes/diff_audits.sh
```

Полные локальные JSON и журналы прогонов — `build/irq-validation/results.json`, `phases/`, `suite/`, `recheck/`, `extra/`, `long/`. Готовые ROM собраны штатным `build_splash.py --quick` для обеих языковых сборок.
