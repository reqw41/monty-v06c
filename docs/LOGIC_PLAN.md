# Нативная логика на i8080 через JS-модель (с 26.10.2026)

Решение владельца: логику Coleco/MSX переписать заново — сначала **JS-модель** (сверка с MSX по итерациям),
потом **i8080 вручную с оптимизацией** (сверка с моделью/эталоном). Программный VDP заменяется прямыми
вызовами: логика сама рисует в экран Вектора (тайлы — кэш изображений + POP, спрайты — ячейки фона в
невидимой плоскости + POP), без виртуальной VRAM и сравнения «было/стало». Образец — jetpac-v06c
(docs/LOGIC_PLAN.md там).

Нынешняя сборка (транслятор tools/z2i.py + слой OS7) остаётся рабочим запасным вариантом и эталоном
поведения на Векторе.

## Этапы
0. **Эталон** — модель MSX tools/msx1.js в режиме coop (кадр — в ожиданиях A5CA/8C19), шаг = итерация
   главного цикла A5D1 -> A5D1. Трассы по сценариям: ОЗУ игры 7000-733F, таблица имён, цвета, атрибуты
   спрайтов, банки шаблонов, звук (байты SN76489 по кадрам). Сценарии: случайная игра на уровнях 1-3
   (с жизнями), обход 99 комнат телепортом, смерти разных видов, двери/ключи, лазеры, факел (темнота),
   сокровищница, конец уровня. Инструмент — по образцу tools/lockstep.js.
1. **JS-модель** (src/model/): главный цикл, процессы таблицы A8A1 (91E5, 8F5F, 88D1, A8D6), обработчик
   кадра A9B3 (враги A7A1, анимации A92F, звук AC6D, ввод 8C1F), комнаты (декодер — tools/roomdec.py уже
   есть), герой (состояния 8913: ходьба, прыжок, падение, лестница, верёвка, цепь, гибель), предметы,
   двери, счёт, инвентарь. Состояние — те же ячейки 7000-73FF (чтобы сверять 1:1); вывод — события
   «клетка (x,y) := тайл», «спрайт k := (x,y,имя,цвет)», «цвета группы», «банк R4».
2. **i8080** (src/vec/native/): та же раскладка ОЗУ игры, логика по модели с оптимизацией (регистры вместо
   ячеек, таблицы вместо цепочек сравнений), вывод напрямую.
3. **Сверка**: модель против эталона MSX; i8080 против модели (ОЗУ игры + события вывода).

## Уже сделано для вывода (в нынешней сборке)
- Банки шаблонов: банк 0 — E000, различия банков 1, 2, 5 — только 17 тайлов (04-06, 38, A0, A3, A4, A7,
  B8-BA, D0-D5), dslot/dstore; сверка шаблонов (PATS=1 в tools/lockstep.js) — совпадение.
- Невидимая плоскость: E000 банк 0, E800 dslot, E900 различия, F300 кэш тайлов (tslot), F400 изображения,
  F900-FEFF ячейки фона спрайтов (6 x 256), FF00-FFFF свободно.
- Кэш изображений тайлов и вывод клетки через POP (src/vec/cell.asm).
